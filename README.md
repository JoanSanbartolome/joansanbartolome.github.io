# Portafolio Profesional - Joan San Bartolome Ferri

> **Ingeniero Electrónico Industrial & Desarrollador RTL / FPGA / Sistemas Embebidos**  
> Máster Universitario en Ingeniería de Sistemas Electrónicos | Máster en IA Aplicada y Optimización de Procesos Productivos

- **Hardware & FPGAs:** Intel Cyclone IV (DE2-115), Intel Cyclone V (SoC), Gowin Tang Nano 9k, STM32 (Cortex-M), ESP32, Raspberry Pi.
- **Entornos EDA & Simulación:** ModelSim / QuestaSim, Intel Quartus Prime, STM32CubeIDE, Gowin EDA, Antigravity IDE, VS Code.
- **Diseño CAD & PCB:** Altium Designer, KiCad, Cadence Virtuoso, Proteus, AutoCAD, Fusion 360.

## 🚀 Instalación y Compilación Local

Si deseas clonar y compilar este proyecto en un entorno local:

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/JoanSanbartolome/curriculum_web.git
   cd curriculum_web
   ```

2. **Instalar dependencias de desarrollo:**
   ```bash
   npm install
   ```

3. **Compilar estilos Tailwind CSS:**
   ```bash
   # Compilación de producción minificada
   npm run build

   # Modo desarrollo en escucha activa (watch)
   npm run dev
   ```

4. **Visualización:**
   Abre el archivo `index.html` directamente en tu navegador preferido.
